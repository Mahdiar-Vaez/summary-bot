# 🎙️ ربات هوشمند خلاصه‌ساز ویس تلگرام (Telegram Voice Summary Bot)

این پروژه یک ربات تلگرام سریع و سبک بر پایه `Python 3.12` و `aiogram 3` است که ویس‌های طولانی (۵ تا ۱۰ دقیقه‌ای) را دریافت کرده، زبان ویس (فارسی یا انگلیسی) و نام گوینده را تشخیص می‌دهد و خلاصه‌ی دقیق صحبت‌های طرف مقابل را در قالب:
> **📌 خلاصه صحبت‌های مهدیار:**
> مهدیار میگه که...

تحویل می‌دهد. همچنین دکمه‌ی شیشه‌ای **«📜 مشاهده متن کامل ویس»** را زیر پیام قرار می‌دهد.

---

## ✨ ویژگی‌های کلیدی
- **بدون بار پردازشی روی سرور:** سرور فقط نقش گیت‌وی (Orchestrator) را دارد و نیازی به GPU یا رم بالا ندارد.
- **معماری `Fallback Chain` چندلایه و ۱۰۰٪ رایگان:**
  - **تبدیل صوت به متن (STT):** ابتدا با `Groq Whisper-large-v3` (تبدیل ویس ۱۰ دقیقه‌ای در ۳ ثانیه)؛ در صورت محدودیت، سوئیچ خودکار به `Cloudflare Workers AI Whisper`.
  - **خلاصه‌سازی هوشمند (LLM):** ابتدا با `Google Gemini 2.0 Flash`؛ در صورت محدودیت، سوئیچ خودکار به `Groq Llama-3.3-70B` و در نهایت `OpenRouter Free`.
- **تشخیص هوشمند نام گوینده:** استخراج خودکار نام گوینده از پیام‌های مستقیم، ریپلای‌شده در گروه (`/summary` یا `/خلاصه`) و فورواردشده (حتی کاربران با فوروارد مخفی یا کانال‌ها).

---

## 🚀 راه‌اندازی سریع

### ۱. تنظیم کلیدها در فایل `.env`
یک کپی از فایل `.env.example` با نام `.env` بسازید:
```bash
cp .env.example .env
```
و سه مقدار زیر را در آن قرار دهید:
- `TELEGRAM_BOT_TOKEN`: دریافت از [@BotFather](https://t.me/BotFather)
- `GROQ_API_KEY`: دریافت رایگان از [console.groq.com](https://console.groq.com/keys)
- `GEMINI_API_KEY`: دریافت رایگان از [aistudio.google.com](https://aistudio.google.com/apikey)

### ۲. اجرا روی سیستم یا سرور با پایتون
```bash
.\.venv\Scripts\python.exe -m src.main
```

### ۳. اجرا روی سرور لینوکس با Docker
```bash
docker compose up -d --build
```

### ۴. اجرای تست‌های خودکار
```bash
.\.venv\Scripts\pytest.exe -v
```
