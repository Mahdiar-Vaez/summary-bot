# Telegram Voice Summary Bot v0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Persian/English TTS to Google's flagship `gemini-3.8-flash-tts` model chain, remove audio summary buttons from group/channel chat history summaries, render all bot outputs with clean Telegram Markdown/HTML formatting, and eliminate 503 latency by optimizing the Gemini model fallback order.

**Architecture:**
1. **`GeminiTTSProvider` (`src/services/tts/gemini_tts.py`)**: Uses Google Gemini REST `generateContent` with `responseModalities: ["AUDIO"]` and `speechConfig` across `gemini-3.8-flash-tts` -> `gemini-3.8-flash-lite-tts` -> `gemini-3.1-flash-tts-preview`, with `EdgeTTSProvider` (`fa-IR-DilaraNeural` + proxy support) as fallback.
2. **Telegram Markdown-to-HTML Renderer (`src/bot/formatting.py`)**: Safely converts LLM Markdown (`**bold**`, `*italic*`, `` `code` ``, headers) into valid Telegram HTML (`<b>`, `<i>`, `<code>`) and sends messages with `parse_mode="HTML"` so raw `**` asterisks never appear and entity parse errors never happen.
3. **Chat Summary Output Cleanup (`src/bot/handlers.py`)**: Removes the TTS inline keyboard (`reply_markup=None`) from `_run_chat_history_summary`.
4. **Latency Optimization (`src/main.py`)**: Prioritizes fast, non-throttled models (`gemini-3.5-flash-lite`, `gemini-3.8-flash`, `gemini-3.1-flash-lite`, `gemini-3.5-flash`) to eliminate the 16-second 503 timeout delay observed in server logs.

**Tech Stack:** Python 3.12, `aiogram` 3.x, `httpx`, `pytest`.
